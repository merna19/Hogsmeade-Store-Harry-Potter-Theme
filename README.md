# Hogsmeade-Store-Harry-Potter-Theme
Inspired by the enchanting world of Harry Potter, this project brings the charm of Hogsmeade to life through a fictional online store.

I built the entire frontend using HTML, CSS, and Bootstrap 5 to ensure a responsive and visually appealing layout. The design adapts beautifully across devices—from desktops to smartphones—thanks to Bootstrap’s grid system and custom media queries.
